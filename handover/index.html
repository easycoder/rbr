Continuity

Change the site Room By Room uses

This page exists so that a heating installer or their technical advisor can move the service to a new website if the maintainer is no longer able to run it. You need the sealed passphrase supplied with the system, and the address of a new site that is already prepared.

Nothing changes immediately. A request waits 14 days before any controller is told about it. The maintainer is notified at once and can cancel it during that period. If the new site is not ready when the waiting period ends, the handover fails and nothing switches.

Cancel a handover request

This link cancels the request named below. It can only be used while the 14-day waiting period is still running.

Request

The passphrase from the sealed envelope. It is not the system password and it is not stored on this site.

The site's home address, starting with https://. Do not add /heat or any other path unless the new site really lives under one.

What the new site has to provide

Before this form accepts the address, the site is checked for the files the controllers themselves rely on: a readable /heat/version release stamp and a /credentials.php endpoint that refuses an unauthenticated request. It also needs a valid HTTPS certificate. The same two checks are made again when the waiting period ends.

After a successful handover each controller will be told, on its next update check, to use the new site and the MQTT broker named by that site's credentials. A controller that cannot reach the new site keeps running its existing heating plan; only updates and the app's connection to it are affected.

If you submitted this by mistake

Use the cancellation link in the notification email, or ask the maintainer to cancel it. Submitting another request is not possible until the current one is cancelled or has failed.
