| 2026-10-24 | AllSpeak JS runtime | Give a parked `send … and assign reply` its own reply slot instead of one `replyVar` / `replyResume` per program. Per-send (nested) slots, or a clear runtime error when a second send would overwrite a parked one, would make the failure loud at worst. | `shell.allspeak` holds a map that arrives while a sheet editor is open (`PendingMap`), refuses to apply it there, and flushes it after the module's reply lands (`FlushPendingMap`), so the second send never starts while the slot is held. `tests/pwa-schedule-save-check.js` guards the workaround. | Open |
